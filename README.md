## 网页功能

- **移动端优先**：竖屏滚动阅读 4 页报告
- **点击放大阅读器**：点任意页面全屏打开，支持双指缩放、滚轮缩放、双击放大、旋转、复位、拖动
- **目录抽屉**：右下角"目录"按钮，点击跳转对应页
- **页码指示**：滚动时顶部实时显示当前页
- **原版 PDF 下载**入口
- 因报告为 A4 横向版面，页面顶部有横屏/放大使用提示
